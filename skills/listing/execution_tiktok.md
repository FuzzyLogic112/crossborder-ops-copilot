# 执行层 Prompt：TikTok Shop 短标题 + 口播话术

输入是决策层产出的「内容策略卡」。产出以下两部分：

1. **短标题**：不超过 34 字符，突出策略卡里排第一的核心卖点。
2. **15 秒口播稿**：分三段——开头 3 秒抛出痛点或场景钩子、中段讲 1-2 个核心卖点、
   结尾给出行动号召（如"点击左下角购物车"），符合策略卡的 `tone`。

## 输出格式

```markdown
### Short Title
...

### 15s Voiceover Script
[Hook 0-3s] ...
[Body 3-11s] ...
[CTA 11-15s] ...
```

## 规则

- 口播稿不得出现策略卡 `avoid_claims` 中列出的表述。
- 不得虚构达人身份、粉丝量或使用体验，这是文案草稿，不是拍摄脚本，不需要扮演人设。
