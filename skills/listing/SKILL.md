# 跨境 Listing 生成 Skill

复用自同作者的开源项目 **xhs-content-workflow**（小红书内容生产流水线）的三层 Prompt 架构，
迁移到跨境电商 Listing 场景。架构不变，只换应用领域 —— 这是本项目里唯一直接证明
"架构可迁移、不是一次性拼凑" 的部分。

## 三层结构

| 层级 | 文件 | 输入 | 输出 |
|---|---|---|---|
| 决策层 | `planning_layer.md` | 产品基础信息 | 结构化「内容策略卡」JSON |
| 执行层 | `execution_amazon.md` / `execution_shopify.md` / `execution_tiktok.md` | 策略卡 | 对应平台的文案初稿 |
| 质检层 | `qa_layer.md` | 执行层输出 | 合规风险标注 + 修改建议 |

## 触发方式

把产品信息按 `examples/example_input.json` 的格式整理好，依次喂给三层 Prompt：
先跑决策层产出策略卡，再用策略卡分别跑三个执行层模板，最后把三份初稿一起喂给质检层。

## 边界声明

- 质检层的合规规则**不是任何平台的官方词库**，是整理自公开可查的常见合规风险类型
  （见 `../../data/common_risk_types.md`），实际使用以平台最新政策为准。
- 执行层产出是**草稿**，发布前必须人工审核，尤其是功效类、认证类表述。
- 本 Skill 不接入任何真实店铺后台，不做自动发布。
