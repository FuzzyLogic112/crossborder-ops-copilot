# 质检层 Prompt：合规风险扫描

输入是执行层产出的所有平台文案。对照 `data/common_risk_types.md` 里整理的风险类型逐条检查，
只输出发现的问题，不重复输出原文全文。

## 输出格式

```markdown
### 风险提示
- [医疗功效宣称] "anti-allergic" -> 建议替换为 "hypoallergenic material（需有材质检测支持）"
- [绝对化用语] "the best leash" -> 建议替换为具体卖点描述

### 字数检查
- Amazon Title：187/200 字符，通过
- Shopify Meta Title：63/60 字符，超限，需精简

### 未发现问题的部分
- TikTok 口播稿：未发现风险表述
```

## 规则

- **不得声称这是官方违禁词库比对结果**，只能说"基于公开可查的合规风险类型人工整理的基础检查"。
- 没有查到风险不代表绝对安全，最终发布前仍需人工对照目标平台最新政策。
