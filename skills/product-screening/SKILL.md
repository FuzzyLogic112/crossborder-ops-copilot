# 选品初筛

**没有运营经验的人做选品，最大的问题不是眼光差，是不知道该看什么。**
看到榜单上卖得好就想跟，但榜单卖得好不等于你能赚钱 ——
它可能是重货（运费吃光利润）、可能是禁限售、可能它靠本地仓而你是跨境直发。

这个 skill 把判断流程固化下来：**先过四道硬性淘汰，再打六维度分**。
顺序不能反 —— 硬淘汰是一票否决，过不了就不用打分了。

---

## 一、四道硬性淘汰（任何一条中了就直接放弃）

### ① 合规红线

| 信号 | 处理 |
|---|---|
| 医疗器械、药品、保健功效宣称 | **放弃** |
| 带电池（尤其锂电）、带磁、液体、粉末、气雾 | 查目标市场空运/海运限制，多数要走特殊渠道 |
| 儿童用品、母婴、食品接触 | 需要目标市场认证（CPC / FDA / CE 等），**新手慎入** |
| 明显的品牌仿款、专利外观 | **放弃**，侵权赔付远超利润 |
| 刀具、打火机、仿真枪 | 多数平台禁售或强限制 |

**新手建议**：第一个品避开以上全部。宁可做"无聊但安全"的品。

### ② 重货直接出局

**跨境头程按公斤计费。** 重量是新手最容易忽略、也是最致命的变量。

```
粗算：物流费 ≈ 首重费 + 重量(kg) × 每公斤单价
美国线参考量级：首重 ¥15 + 每公斤 ¥20（实际以货代报价为准）
```

| 重量 | 判断 |
|---|---|
| < 0.5kg | 理想 |
| 0.5–2kg | 可做，但要算清楚 |
| 2–5kg | 除非客单价很高（>¥300），否则难做 |
| **> 5kg** | **跨境直发基本不成立**，放弃 |

**真实案例**：美国站宠物用品榜第一是 40 磅（18kg）猫砂。
按上面的量级算头程运费约 ¥375，而它售价约 ¥163。
**运费是售价的两倍多，再便宜的采购价也救不回来。**
它能卖是因为本地仓发货，不是从中国发。

> **重量往往写在竞品标题里**（`Cat Litter 40 lb`），先看标题再动心。

### ③ 贡献利润为负

```
贡献利润 = 售价 − 采购价 − 包装 − 物流 − 平台佣金 − 支付费 − 退货准备金
```

**注意佣金和支付费是按售价的百分比收的**，所以：

```
保本价 = 固定成本 ÷ (1 − 费率合计)     ← 是除法，不是乘法
```

用乘法会系统性低估保本价，**越贵的品错得越多**。

**贡献利润 ≤ 0 就是一票否决，不管其它维度多好看。**

### ④ 数据不全不下结论

缺采购价、缺重量、缺计划售价 —— **判"无法测算"，不是判"通过"**。

**这条最容易被忽略。** 把空值当 0 会让商品看起来免费、利润爆表、评分满分。
**没有结论比错误的结论安全得多。**

## 二、六维度打分（过了硬淘汰才打）

| 维度 | 满分 | 怎么判断 |
|---|---|---|
| **需求稳定性** | 25 | 榜单排名稳不稳、评价数是否持续增长、是不是季节性单峰 |
| **竞争缺口** | 20 | 翻竞品差评，找反复被抱怨但没人解决的点 |
| **贡献利润** | 20 | **系统算**，见上面公式 |
| **物流友好** | 15 | 重量、体积、易碎、带电带磁带液 |
| **合规** | 10 | 见硬淘汰① |
| **内容可做性** | 10 | 能不能拍出和竞品不一样的图和视频 |

**六项里只有「贡献利润」是算出来的，其余五项都是人的判断。**
这不是缺陷 —— 选品本来就不能全靠算。工具的作用是
**让能算清的那一项不可能拍脑袋，并且给它一票否决权**。

### 分数怎么用

| 总分 | 建议 |
|---|---|
| ≥ 75 | 值得深入：去问供应商报价，做详细测算 |
| 60–75 | 备选：先放着，有更好的就放弃 |
| < 60 | 不做 |

**别迷信分数。** 五项人填的分带着你的主观判断，
换个人打可能差 15 分。分数的价值在于**逼你把每个维度都过一遍**，不是给你一个客观真理。

## 三、竞争缺口怎么找（新手最不会的一步）

不是看竞品有什么，是**看竞品差评里反复出现什么**。

1. 打开竞品 Listing → 筛选 **1–3 星评价**
2. 按 "Most recent" 排序，看最近 50 条
3. 记下反复出现的抱怨（出现 3 次以上才算信号）
4. 判断：这个问题**你能解决吗**？解决它要加多少成本？

**能解决 + 加成本可控 = 真缺口**
**解决不了 或 解决了就亏本 = 不是你的机会**

常见的真缺口：包装易破、尺寸标注不清导致买错、配件缺失、说明书看不懂。
常见的假缺口：「质量不好」（太笼统）、「物流慢」（不是产品问题）、「价格贵」（打价格战没意义）。

```json
{
  "product_name": "HydroJug Traveler 40oz 保温杯",

  "currency": "USD",
  "fx_rate": 7.1,

  "cost_price_cny": 29.0,
```

## 六、这个 skill 的边界

- **不替你做决定。** 它给的是结构化判断，最终拍板的是你。
- **物流费率是估算量级。** 货代报价一对一议价、不公开挂牌，
  真做决策前必须拿到实际 rate card 替换。
- **退货率无法预知。** 模型里的退货率是占位值，只能用自己店铺历史订单统计。
- **不做市场规模预测。** 谁也不知道下个季度这个品还火不火，别信任何号称能预测的工具。
- **不抓供货平台价格。** 1688 / 阿里的价格在登录墙后面，报价靠人工询价。
