# 跟价决策

**新手看到竞品降价的第一反应是跟。这是最容易亏钱的动作。**

跟价之前必须回答三个问题：
1. **我的保本价是多少？** —— 跟到哪里就亏了
2. **对方为什么降？** —— 清库存、新品冲榜、还是长期价格战，应对完全不同
3. **除了降价，还有别的选择吗？** —— 降价是最后手段，不是第一反应

---

## 一、先算自己的底线

```
保本价 = 固定成本 ÷ (1 − 费率合计)
```

固定成本 = 采购价 + 包装 + 物流
费率合计 = 平台佣金率 + 支付费率 + 退货准备金率

**是除法。** 佣金和支付费按售价百分比收，售价越高平台抽走的绝对额越大。
用乘法会低估保本价，**越贵的品错得越多**。

```
示例：固定成本 58.50，费率 23%
      保本价 = 58.50 ÷ 0.77 = ¥75.97
      用乘法算成 58.50 × 1.23 = ¥71.96 ← 差 4 块，而这 4 块全在亏损区
```

**跌破保本价 = 卖一件亏一件。** 这条线不能过，除非你是在有意识地做清仓。

同时算出：

```
贡献利润率 = 贡献利润 ÷ 售价
保本 ROAS  = 1 ÷ 贡献利润率
```

**保本 ROAS 是投放的底线**：广告花 1 块必须带来这么多销售额才不亏。
降价会同时压缩贡献利润率并抬高保本 ROAS —— **降价其实是在削弱你的投放能力**，
这一点新手几乎都没意识到。

---

## 二、判断对方为什么降

| 信号 | 大概率原因 | 应对 |
|---|---|---|
| 降幅小（<5%）、持续几天 | 日常调价测试 | **观察，不动** |
| 降幅大（>20%）、伴随"Deal"角标 | 平台活动 / 秒杀 | **不跟**，活动结束会回弹 |
| 降价 + 评价数增长突然加快 | 新品冲榜期砸钱 | **不跟**，冲榜期通常 2–4 周 |
| 降价 + 库存显示"仅剩 x 件" | 清库存 | **不跟**，卖完就回去了 |
| 降价 + 长期维持 + 多个竞品跟进 | 真的价格战 | 认真评估，见下节 |
| 只降了一个变体 | 变体清理 | **不跟** |

**多数降价不需要跟。** 先看 3–5 天再说 —— 跟错方向的代价比慢几天大得多。

---

## 三、真要应对，降价是最后一个选项

按这个顺序试：

| 顺序 | 手段 | 为什么排这么前 |
|---|---|---|
| 1 | **什么都不做，观察 3–5 天** | 多数降价会回弹，跟了反而被套住 |
| 2 | **优化转化** | 主图、标题、五点、评价运营 —— 提高转化等于变相降价但不损失毛利 |
| 3 | **加赠品 / 改套装** | 提升感知价值，不动单价，保住贡献利润率 |
| 4 | **调投放**，加预算抢曝光 | 只要 ROAS 还在保本线以上就划算 |
| 5 | **限时折扣**（不改日常价） | 可回退，不破坏价格锚点 |
| 6 | **真正降价** | 最后手段，且必须算到保本价 |

**第 3 条特别值得试。** 竞品降 10%，你送一个成本 ¥3 的配件，
感知价值可能远超 ¥3，而你的贡献利润几乎没变。

---

## 四、如果决定降，降到哪里

```
可降空间 = 当前售价 − max(保本价, 目标毛利价)
```

三条线，从松到紧：

| 线 | 含义 | 什么时候能碰 |
|---|---|---|
| 目标毛利价 | 达到预期毛利率的价格 | 日常经营守住这条 |
| **保本价** | 贡献利润为 0 | **绝对底线**，只有清仓才能跌破 |
| 竞品价 | 对方的价格 | **没有义务跟到这里** |

**关键认知：跟不到就不跟。**
如果竞品价已经低于你的保本价，说明他的成本结构和你不一样
（可能是工厂直营、可能有本地仓、可能在亏钱冲量）。
**这个仗你打不赢，该换战场而不是硬扛** —— 换差异化卖点、换细分人群、换品。

## 七、这个 skill 的边界

- **不自动改价。** 输出的是建议，改价必须你自己在平台后台做。
  这个项目不提供任何自动改价接口。
- **推断原因靠信号，不是事实。** 对方为什么降价只有对方知道，
  这里给的是概率判断，会有错。
- **不预测价格战走向。** 谁先撑不住没人算得出来。
- **退货率与物流费率是估算值。** 它们影响保本价，真决策前要用自己的实际数据替换。
